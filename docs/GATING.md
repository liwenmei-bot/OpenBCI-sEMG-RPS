# 活动分数、门控与二分类

默认`classic + legacy + source`中，活动门控与SVM分类使用不同信息。活动分数决定是否允许发出一次结果；SVM依据20维特征决定石头还是布。活动值较高不会直接判石头，较低也不会直接判布。

## legacy活动分数

对每个200 ms滤波窗口，计算四通道RMS，除以各通道参考值：

\[
r_c=\frac{\operatorname{RMS}_c}{b_c},\qquad A=\operatorname{mean}\bigl(\operatorname{Top2}(r_1,r_2,r_3,r_4)\bigr).
\]

`b_c`保存于门控JSON的`noise_reference_rms_uv`。它来自源Run1基线候选窗口的各通道RMS中位数，并设有很小的数值下限。这是无量纲相对分数，不是μV，也不是分类概率。

准备门控时以Run1候选分数的99%分位数构造ON候选，以基线分布与ON计算OFF；联合比较3窗3票或5窗4票以及不同等待时间，在Run2上选择。实际采用的全部参数写入`replay_detector_config.json`，候选比较另存CSV。Run3+4不会参与选择。

进度条上限为`2×ON`，所以ON大约在50%位置。条长只是活动相对于门限的位置，不是动作完成百分比。旧日期参考、电极位置或噪声变化都可能使今天放松时的`A`升高；应先核对数据流并重新校准，再用有标签的记录比较参数效果。

## 什么时候发出结果

| 条件/状态 | 行为 |
|---|---|
| 启动后尚未观察到放松 | 需要`A≤OFF`连续`release_windows`窗，才能准备下一次 |
| 已准备，但`A<ON` | 不发出新结果；OFF与ON之间为滞回区 |
| `A≥ON` | 累积启动窗并等待`settle_seconds`，随后收集分类票 |
| 票窗内某一类别达到`minimum_votes` | 当前活动仍达ON且数据有效时，输出一次结果 |
| 同一次动作持续保持 | 锁定该事件，不重复输出 |
| 再次持续放松 | 达到释放条件后，允许下一次动作 |
| 数据过时、连续性中断或数值不可用 | 抑制输出/重置相关状态，等待有效新数据 |

SVM每个可用窗口都可产生候选类别，但候选不一定立刻对外输出。二分类`SVC.decision_function`返回单个有符号间隔，代码转换为两类分数时保留其符号语义；分类本身依模型的标准化器与SVM，不能用绝对值比较把符号丢掉。

动作强度不够、尚未释放、投票类别交替、数据陈旧是不同原因，分别查看`window_trace.csv`的活动、状态、预测与时间戳。一直保持握拳时已经输出过一次，则需要真正放松才能再识别；这不表示持续重复输出功能失效。

## 覆盖阈值用于什么

`--gate-profile source`原样沿用配套配置。`--gate-profile trial`显式采用以下临时参数：

| ON | OFF | 等待 | 投票 | 释放 |
|---|---|---|---|---|
| 7.2 | 7.0 | 0.2秒 | 最近5窗至少4票 | 连续5窗 |

这些数值来自少量历史截图，未通过独立验证。它们不能证明布与放松可被稳定分离。OFF提高会更容易确认放松，但若布也低于OFF，可能把布当成释放；ON降低能增加敏感度，也可能增加静息误触发。不能只看一张截图就同时把所有值改成“最佳阈值”。

`classic`还允许显式传`--gate-on`、`--gate-off`、`--gate-settle-seconds`、`--gate-vote-windows`、`--gate-min-votes`、`--gate-release-windows`。覆盖只用于此次实时运行，原始模型和JSON保持冻结；日志记录实际配置。数值必须满足`0≤OFF<ON`及有效的票数约束。legacy的绝对分数覆盖不可与robust的z分数混用。

## 其他门控方式

`classic --activity-mode robust`可测当前静息参考，使用RMS相对中位数与MAD的偏离；`extended`另外保留当前静息门控与响应配置。它们与legacy分数的尺度不同，不应把6、7.2等数值横向比较。当前静息测量及动作期间参考冻结不等于重新训练分类器，具体实现与历史版本见`docs/VERSIONS.md`。

`extended --trigger-mode manual`由按钮启动固定时长采样，绕过自动活动门控；它用于比较“何时截取信号”的影响，不会提前取得真实类别。无论哪种模式，真实动作按钮都在预测后进入统计，不传回SVM拟合或门控重置。
