# 采集与数据约定

此项目使用OpenBCI前四个EXG通道、250 Hz采样率，默认单位为μV。LSL流可以有8个通道，默认只读取第1—4通道。程序中的`--channels`为从1开始的序号。更换通道、单位或预处理参数后，需要重新生成与之匹配的特征、模型和门控。

| 项目 | 二分类主线 | 三分类保留流程 |
|---|---|---|
| 正式采集 | 4 Run，每Run 12 Trial，共48次 | 4 Run，每Run 18 Trial，共72次 |
| 每Run类别次数 | 石头6、布6 | 石头6、剪刀6、布6 |
| 模型类别ID | 0=石头，1=布 | 依三分类模型映射 |
| 动作Marker | 11=石头、13=布 | 11=石头、12=剪刀、13=布 |
| 其他Marker | 20=动作结束；90=作废 | 同左 |
| Run边界 | 开始101—104，结束111—114，中止121—124 | 同左 |

二分类默认配置见`configs/rp_collection.json`；三分类见`rps/collection/config_rps_emg.json`。采集提示程序通过UDP向`127.0.0.1:12350`发送Marker。OpenBCI GUI需要接收同一端口，并单独保存包含Marker的原始TXT。提示程序生成的事件CSV不能替代板卡原始记录。

二分类提示顺序为静息2.5—3.5秒、提示1秒、动作4秒、返回0.5秒；每Run内平衡随机排列。预处理默认提取动作Marker后0.5—3.5秒的核心段。PsychoPy正式模式应显式写`--mode formal`，默认pilot不是完整正式协议。

信号使用有状态的单向SOS滤波：50 Hz陷波、20—100 Hz带通。200 ms窗、100 ms步长；每通道依次提取MAV、RMS、WL、ZC、SSC，共20维特征。离线、回放与实时必须遵守模型内的相同配置，不能只修改实时滤波后直接沿用旧模型。

旧三分类TXT或预处理目录可用于重新训练二分类：只保留Marker11和13，Marker12记入排除清单。剪刀动作及其附近不能直接当作真实静息。质量清单中保留异常与作废原因；是否参与拟合依各阶段的数值可用标记决定。

`rest_candidates.csv`是根据采集时序提取的基线候选，不等于逐帧人工确认的静息真值。没有完整静息真值时，不把候选区域上的触发数命名为真实静息误触发率。

当天校准的Run1用于拟合候选，Run2选择当天权重；冻结选择后以历史数据与Run1+2拟合最终当天模型。Run3+4不参与拟合与参数选择。门控参考来自源Run1，门控候选在源Run2上选择。真实动作标记只在相应训练或评分阶段使用，实时检测器没有Marker真值输入。
