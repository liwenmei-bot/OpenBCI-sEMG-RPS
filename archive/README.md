# 历史实时源码快照

binary/v1_0_0至v1_4_0保存扩展分支7个版本，每个目录包含当时的实时脚本与run入口。classic_v1_0_1保存当前classic分支源码；repository_integration_20261115保存当前整合入口。

classic1.0.0仅找到构建记录，未找到可独立核对的完整原始快照，因此没有生成同名文件冒充原件。全部来源、默认参数、逐行差异与验证范围见[详细历史](../docs/BINARY_VERSION_HISTORY.md)。

旧run入口需要其当时配套阶段模块；这些目录是来源归档，不是每版都附带完整独立工程。当前运行从根目录run.py进入，历史guided版本仅用于追溯。
